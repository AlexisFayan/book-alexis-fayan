# Book — Alexis Fayan

Portfolio en ligne d'Alexis Fayan, Project Manager IA & Cloud chez Orange Business — Cloud Avenue (Lyon).

Site statique (une page, `index.html`), sans dépendance. Déployable tel quel sur Vercel.

## Déploiement Vercel
1. Importer ce dépôt sur [vercel.com/new](https://vercel.com/new).
2. Framework preset : **Other** (site statique, aucune configuration nécessaire).
3. Déployer. L'URL de production sera `https://<nom-du-projet>.vercel.app`.
